# EGO Flow Images

Read [the shared operating contract](../ego-flow-setup/references/operating.md) first. If local execution is unavailable or the browser cannot connect, use the packaged setup skill instead of silently switching execution engines.

## Prepare

Resolve the user's actual request, authorized local references and destination. Reuse this goal's existing TaskSpace and verified project. Create or rename a project only within the user's requested scope.

Open Flow and inspect current state. Enter the authenticated workspace or hand off if sign-in/challenges are needed. Select Image using observed controls. If the UI offers Flow Agent mode, ensure its actual state permits manual configuration. Do not blindly toggle or assume the control is present.

Read the available models, aspect ratios, resolutions and count controls from the current interface. Honor a named model if available. Historical Nano Banana names do not imply a guaranteed model or default. If the user has not chosen, propose a currently available suitable setting at the checkpoint; do not invent prices.

Upload only the selected references through the documented local file APIs, verify they are attached, then fill the prompt. Keep exact brand text, source identity and other user constraints. For advertising work, distinguish draft-generated lettering from an approved logo.

## Submit and wait

Capture the live settings and quoted total cost after configuring the references and prompt. In checkpoint mode, report the prepared job and wait for approval; do not click Generate. Explicit auto authorization applies only within the shared spending rules.

Submit once. Correlate the new result/job with this prompt rather than accidentally downloading an older card. If submission is ambiguous, inspect the same project before any retry. Use bounded checks of observed queued/running/finished state, not a perpetual blind loop. Keep the user informed during a long run. If not completed in this reply, say so rather than treating a submitted job as a result.

## Inspect and download

Inspect the candidate's visual content when available: source identity, face, hands, props, text and framing. This is separate from the DOM's success status.

Read the live download menu. Prefer an approved original-size/no-additional-charge option; do not assert that any resolution is always free. Arm the event before downloading, save to a new absolute output name, and verify a non-empty image file with expected type and dimensions. End the browser work using the shared lifecycle. Report completed files and remaining review needs.
