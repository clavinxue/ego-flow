# EGO Flow for GPT

**ChatGPT 桌面本地 Work / Codex 版**。与仓库根目录的 Antigravity 版并存，不替换原版。

本插件让 Agent 使用已安装的 EGO Lite (`ego-browser`)，在 Google Flow 网页上上传参考图、配置图片或视频、确认点数、生成并下载到本地。

## 使用前提

- 在有本地命令执行权限的 ChatGPT 桌面本地对话或 Codex 中使用。
- 同一台电脑已安装可用的 EGO Lite；Google 登录由你在浏览器里完成。
- 按宿主要求批准浏览器访问和文件访问。

插件不包含 EGO Lite，不自动安装或升级浏览器，不提供远程桥接，也不会让纯云端对话凭空访问电脑。无需填写 OpenAI API Key 或 Google API Key；实际图片/视频由 Google Flow 处理，费用按你的 Google 账户与当前界面为准。

## 安装和第一次使用

使用发布的 GPT 版插件入口安装；或者把仅含 `plugins/ego-flow-gpt/` 这一插件目录的 ZIP 导入受支持的插件创建/导入入口。**不要把整个双版本仓库 ZIP 当作一个插件导入**，它包含两个插件根目录。

安装后先说：

> 检查 EGO 和 Google Flow 的连接，不生成、不消耗点数。

看到“Flow 可打开”不代表已经登录；插件会分别报告本机连接、页面、登录和点数状态。新装插件如尚未在当前对话加载，换一个已启用它的本地对话再试。

## 提示例子

> 用这两张角色参考图在 Google Flow 准备一条视频：姐姐递给弟弟一张空白卡片。先给我看模型、时长、横竖屏和实际点数，暂时别生成。

> 按已确认的分镜生成，自动模式，总预算不超过我指定的点数。不要付费放大，不要新增镜头或自动重试。完成后下载到我选的文件夹。

`checkpoint` 是默认模式：配置完成、读出实际点数后等待确认。明确的 `auto` 仅适用于已授权范围，不代表无限预算或允许充值。

## 包含的技能

| 技能 | 用途 |
| --- | --- |
| ego-flow-setup | 本机连接、Flow 可达性与登录状态检查 |
| ego-flow-image | 图片、参考图、生成前确认与下载 |
| ego-flow-video | 分镜、Ingredients、首尾帧、视频生成与场景导出 |

## 隐私与费用

通过 EGO 访问的是你本机浏览器。选定的参考图和提示词会上传到 Google Flow；插件不自建服务，不附带 Cookie 或账户凭据。下载、放大、生成费用每次从当前界面读取，不承诺某个分辨率永久免费。
