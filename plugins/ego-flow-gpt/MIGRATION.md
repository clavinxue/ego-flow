# Antigravity → GPT / Work 迁移说明

日期：2026-11-27。基于仓库初始版本 `235c99233cf291dba80ef8e721a11f27c799f08d`。

## 保留的能力

本地 EGO 执行、语义快照优先、相关操作批量执行、参考图直传、本地下载、Ingredients / Frames、分镜与场景导出、生成前点数确认、登录或验证码人工接管。

## 更改

| 原版 | GPT 版处理 | 原因 |
| --- | --- | --- |
| 根 manifest 的展示字段 | 新增独立标准 Agent Plugins manifest，OpenAI 字段放在 `extensions.com.openai` | 由宿主按正式插件格式识别 |
| 未区分云端与本机 | `requires_local_executor: true` | EGO 是本地程序，不虚构云端桥接 |
| `rules/AGENTS.md` 承载必要规则 | 三个技能显式读取打包的共享操作约定 | 不依赖宿主自动载入仓库规则 |
| Antigravity 专属 `BypassSandbox` 参数 | 使用实际宿主的本地执行与审批机制 | 不把其他宿主参数当作通用 API |
| 固定模型名称、时长和费用 | 从当前已登录 Flow UI 校验 | 账户、地区、套餐和产品会变化 |
| 假定某些1080p下载免费 | 读取当次导出菜单和费用 | 防止未经允许的付费放大 |
| 仅靠URL/没有登录按钮推定登录 | 检查工作区、项目控件与可见状态 | 介绍页也可能不显示登录按钮 |
| 超时后容易重复提交 | 增加 submission_uncertain 状态与同项目查重 | 避免多扣一次点数 |
| 默认总是保留标签 | 仅保留当前任务必要项目/结果；诊断页关闭 | 与当前 EGO 所有权规则一致 |
| 只看完成卡片 | 区分页面完成、下载存在和实际视频连续性 | 不把缩略图验收当作全片验收 |

## 结构

原有根目录版本不修改运行行为。本目录是一个完整的独立 GPT 插件，没有 hooks、MCP 服务、安装器、API 密钥或后台进程。宿主可以运行本地命令时直接调用已有 EGO。

## 非付费验收

1. 在没有本地执行能力的对话中：必须说明无法连接，不能假称成功。
2. 只要求连接检查：不得创建项目、上传文件或点击生成。
3. 介绍页可达：只能报告可达，不能报告已登录。
4. checkpoint 配置后：报告已观察的设置和费用，等待批准。
5. 用户接管、验证码或2FA：停止；同一空间等待用户操作。
6. 点击生成后超时：在同项目确认是否已排队，不盲目再点一次。
7. 仅看到1080p菜单：不能推定免费，先读费用。
8. 文件下载：验证真实媒体，不把HTTP错误页当成成品。
9. 用户提供角色包：只上传当前镜头需要的选定文件；不整包上传。

以上是安装后应继续执行的场景验收，不宣称本次均已进行真实付费测试。
